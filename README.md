## 세 프로젝트를 관통하는 것

**1. 성능보다 데이터를 먼저 의심합니다.**
주택가격 과제에서 결정계수 0.51에 만족하지 않고 분포를 다시 본 결과, 예측 대상 값이 5.0에서 잘려 있는 기록 왜곡을 발견했습니다. 왜곡된 992건을 제거한 것이 이후 개선의 출발점이었습니다.

**2. 상관을 원인으로 단정하지 않습니다.**
은행 이탈 분석에서 잔고 0원이 이탈 원인처럼 보였지만, 국가를 고정하자 효과가 사라졌습니다. 실제 교란 요인은 '독일'이었습니다.

**3. 판정 기준 자체를 검증합니다.**
폭염 프로젝트에서는 상위 20% 절단이라는 임의 기준을 폐기하고 Local Moran's I + FDR 보정으로 재설계했으며, 이후 제가 세운 유형 A 정의도 인과 방향을 증명하지 못한다는 이유로 스스로 폐기하고 다시 설계했습니다.
